# AppTracker.swift

## Responsibility
Synchronous macOS application scanner.

## Role
Enumerates `/Applications` and `~/Applications` using `FileManager` to discover installed `.app` bundles. Returns a `ScanResult` populated with `.userApp` items sorted by name.
